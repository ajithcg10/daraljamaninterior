Run:
1. Keep index.html and style.css in the same folder.
2. Open index.html in your browser, or use VS Code Live Server.

Before publishing:
- Replace info@example.com with the client's real business email.
- Replace the WhatsApp number 971500000000 in the wa.me link with the client's WhatsApp number (country code, digits only).
- Replace the illustrative company text and verify all product categories.
- Images and Google Fonts load from external services, so internet is needed.
- The enquiry form uses mailto and opens the visitor's email application. For a real production form, connect a backend or form service.
